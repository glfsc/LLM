实验对话系统 · 局域网预实验包 使用须知
==========================================

【一键启动】
1. 把整个文件夹解压到电脑任意位置（建议桌面），不要只解压部分文件。
   本包已内置运行环境（包内的 node.exe）：这台电脑**不需要安装 Node.js 或任何其他软件**，
   也不要按网上教程去装 Node——装不装都一样，包内自带的那个才是被使用的。
2. 双击「启动预实验.bat」。
3. 第一次启动若弹出「Windows 安全中心警报」：
   勾选「专用网络」→ 点击「允许访问」。不点允许，手机将连不上。
4. 启动后会自动打开浏览器显示登录页；用 admin / admin123 登录即进入管理端，
   手机二维码在管理端「问卷管理」里生成（见下面【问卷二维码怎么给被试】）。
   若没自动弹出，手动用浏览器打开 http://localhost:3000/ （管理端：http://localhost:3000/admin）
5. 重复双击「启动预实验.bat」也没关系：会自动结束上一次没关干净的旧实例再重新启动，
   不用先手动关闭黑色窗口。若 3000 端口被**别的程序**占用，会自动改用下一个空闲端口启动，
   窗口里会写明新的管理地址（此时管理入口是 http://localhost:新端口/admin）。

【手机怎么连】
· 手机必须和这台电脑连同一个 WiFi（或同一个热点）。
· 二维码在管理端生成（见下一条）→ 用手机「相机」扫码 → 选择浏览器打开。
· 微信扫一扫可能打不开，请改用相机扫码。
· 两种组网方式，任选其一：
  (1) 电脑开热点：电脑「设置 → 网络和 Internet → 移动热点」打开，
      手机连上该热点后再扫码。（需要电脑有无线网卡）
  (2) 手机开热点：手机打开「个人热点」，电脑像连普通 WiFi 一样连上这个热点，
      然后手机自己扫码即可。（适合电脑没无线网卡但有网口/能连 WiFi 的情况）
  两种方式手机和电脑都在同一个网里，效果一样；二维码里的地址会自动取本机局域网 IP，
  不需要任何设置。

【问卷二维码怎么给被试】★ 最常用
· 登录管理端（http://localhost:3000/admin）→ 左侧「问卷管理」。
· 每份问卷 = 一个组别。点该行最左边的二维码小图标（在「编辑」左边）→
  弹窗显示该组别的二维码；被试扫码后**直接进入对应组别的作答页**，
  不需要再粘贴任何链接。
· 弹窗里点「保存图片」→ 下载一张海报式 PNG（组别名 + 二维码 + 网址）：
  打印张贴、或发到被试群里都行，被试扫一扫就开始。
· 右上角「手机入口二维码」是通用入口（扫码进系统首页，可手动输入问卷短码）；
  有具体组别时优先用行内二维码。
· 弹窗里的二维码只在电脑与手机同一个网（同 WiFi / 热点）里有效。

【手机连不上时，按顺序检查】
1. 手机是否还开着流量？先关掉，确认连的是同一个 WiFi/热点。
2. 防火墙是否放行：第一次启动会弹「Windows 安全中心警报」，
   「专用网络」和「公用网络」两个都勾上再点「允许访问」。
   手机热点常被 Windows 判为「公用网络」，只勾专用会连不上。
   若已误点拒绝：到「设置 → 网络和 Internet → 属性」，把该网络改为「专用」。
3. 电脑是否同时连着多个网络（如校园网 + 热点）？启动窗口会列出「备选地址」，
   换一个地址用手机浏览器试；或干脆断开其他网络只留一个。
4. 路由器是否开了「AP 隔离」？如有请关闭，或改用热点方式。

【电脑端编辑】
· 在这台电脑的浏览器打开 http://localhost:3000/admin
· 默认管理员账号：admin  密码：admin123（请尽快在系统里改掉密码）
· 管理端可编辑实验/问卷、生成各组二维码（可保存图片）、查看数据和导出 Excel。

【实验完成后 · 数据回收】
· 所有作答数据都保存在本文件夹的 data.db 文件里。
· 回收方式二选一：
  1) 管理端数据页 → 导出 Excel，把 xlsx 文件发回；
  2) 停止服务（关闭黑色窗口）后，把 data.db 文件发回。
· 建议每天实验结束后备份一次 data.db（复制一份、文件名加上日期即可）。

【常见问题】
· 双击 bat 窗口一闪而过：右键「以管理员身份运行」再试；或确认解压完整。
· 窗口提示「Node.js runtime not found」：说明包内自带的 node.exe 不在（多半是解压不完整，
  或被杀毒软件隔离了）。重新完整解压一次；若反复出现，把整个文件夹加入杀毒软件的信任名单。
· 手机扫了打不开：见上面「手机连不上时，按顺序检查」四步。
· 窗口显示 EADDRINUSE：启动器已经自动处理过端口冲突（见上面第 5 条），一般不会再出现；
  万一还是出现，关掉其他占用端口的程序后重新双击即可。
· 被试正在作答时不要重复双击 bat：重复双击 = 重启服务，会中断当前会话；
  已提交的作答都实时写进了 data.db，不会丢。
· 关闭黑色窗口 = 停止服务；已产生的数据不会丢失，下次双击继续使用。
· 想先验证整套流程是否正常：可在电脑浏览器另开一个标签页打开被试链接
  （在「问卷管理」里点「复制」，或直接扫弹窗里的二维码），自己走一遍
  （用 F12 的手机模式模拟手机屏幕），数据会立刻出现在数据页。

有问题请联系研究者。
